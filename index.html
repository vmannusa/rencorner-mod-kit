New PC setup

  1. Download install-rencorner-mirc.ps1 and rencorner.mrc into the same folder.
  2. Right-click install-rencorner-mirc.ps1 and choose Run with PowerShell. It installs official mIRC (winget), copies the script into %APPDATA%\mIRC, and registers it to load automatically.
  3. mIRC opens and asks once for your NickServ password and the mod channel key. Both are stored only in mIRC's local variables file on that PC.
  4. It connects to irc.rencorner.co, identifies, waits 5 seconds, then joins #rc-mods, #rc-aow-admin, #rc-comm-admin, #rc-snipe-admin (using that key) and #rc-aow, #rc-comm, #rc-snipe.
  5. Check: ChanServ should give you +o in #rc-mods. If a channel fails, look in Status for (+k) wrong key, (+i) invite only, or (+R) not identified.

Manual fallback: Tools › Options › Servers › Add irc.rencorner.co, then type /load -rs rencorner.mrc.

/rccompare A B
HW hash, serial and IP for two names. Same HW or serial means almost certainly the same person.
/rcdelreg name
Runs !delreg name in #rc-aow-admin.
/rccheck name
HW hash, serial and IP for one player.
/rchelp cmd
Shows RCAOW's own syntax for a command.
/rc.join
Rejoin all channels now.
/rc.setup
Change the saved NickServ password.
