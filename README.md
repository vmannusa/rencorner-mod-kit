# RenCorner Mod Kit

Setup and command reference for RenCorner IRC moderators.

- Page: https://vmannusa.github.io/rencorner-mod-kit/
- New PC: download `install-rencorner-mirc.ps1` and `rencorner.mrc` into one folder, right-click the `.ps1` and choose **Run with PowerShell**.
- No passwords or channel keys are stored in this repo; the script asks for them on first run.
